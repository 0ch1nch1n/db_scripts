# 验证记录

本包 v1.0 的核心 SQL 已使用 PostgreSQL 16.15 实际执行验证。

测试采用本地独立数据库和测试对象，未连接用户的任何数据库。

已验证的场景：

- 源/目标两个数据库的相同 schema 得到无差异结果。
- 独立重新创建对象后，虽然 OID 和 dropped-column 物理空槽不同，结构与内容仍一致。
- 普通表、空表、分区叶子、传统继承父/子表计数正确，避免重复计数。
- 中文、空格、逗号、引号对象名和包含换行的 CSV 内容可正确导出/导入。
- 函数重载、过程、触发器、视图、物化视图、枚举、Domain、复合类型、聚合主要属性、外部表目录信息能采集。
- 行数相同但字段内容改变，启用内容指纹后能检测到差异。
- 缺对象、多对象、字段定义变化能分类列出。
- 权限变化、序列状态变化、未验证约束列为 REVIEW。
- 两侧相同的已知异常约束仍保留 HEALTH/REVIEW。
- 数据/序列读取权限不足记录为 ERROR；即使两侧错误相同也不会判断为一致。
- 不同采集选项会列出 CONFIG 差异；结构模式明确显示数据 NOT_RUN。
- 指定 schema 缺失会中止；CSV 缺少完成标记会被拒绝。

验证边界：当前运行环境不能建立数据库监听 socket，所以测试使用 PostgreSQL 单用户后端，按 psql 条件变量展开后执行原脚本核心 SQL，并用 PostgreSQL 原生 COPY 验证 CSV 传输与比较。没有完成原生 psql 客户端的连接、元命令、终端输出及 strict 退出码端到端测试。单用户模式也不能代表普通服务器的全部 RLS 行为；RLS 防过滤设置按官方机制实现，仍需在常规服务器上复核。

PostgreSQL 12–15、17–18 的兼容性尚未逐版本实测。首次使用建议先在测试库验证，再用于正式迁移验收；不要把本记录解释成所有版本和环境均已测试通过。
